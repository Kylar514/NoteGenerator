# Field Service Note Generator

**Zero-Deployment PWA for Structured Field Data Entry**

A single-file Progressive Web App that transforms manual pipe-separated data
entry into an intuitive form interface, designed for field technicians working
in challenging conditions.

## The Problem

Field service technicians were required to manually enter complex pipe-separated
values on mobile devices while:

- Sitting in vans or parking lots
- Under customer pressure and time constraints
- Using company-mandated browsers with security restrictions
- Remembering 5 different case formats with 4-6 fields each

**Result:** Poor data quality, technician frustration, and 5+ minutes of tedious
manual entry per case.

## The Solution

A single HTML file that provides:

- **Intuitive form interface** replacing manual pipe syntax
- **Offline PWA capability** for field use without internet
- **Zero deployment required** - just email the HTML file
- **Security-compliant** - 100% client-side, no data leaves the browser

## Key Features

### **Smart Form Logic**

- **5 case types** with tailored fields:
- **Conditional field display** (show/hide based on selections)
- **Dynamic equipment checkboxes** (with "Other" custom input)
- **Automatic formatting** to exact pipe-separated specifications

### **Mobile-First Design**

- **Responsive layout** optimized for smartphone screens
- **Touch-friendly controls** (large buttons, adequate spacing)
- **Dark/light mode** based on system preferences
- **PWA installable** (feels like native app, works offline)

### **Enterprise-Ready**

- **100% client-side** - No servers, no data transmission
- **Single HTML file** - Email-distributable, zero infrastructure
- **Security-policy compliant** - Works within locked-down browsers
- **No dependencies** - Pure vanilla HTML/CSS/JS (no frameworks)
- **Edge-compatible** - Tested with corporate browser restrictions
